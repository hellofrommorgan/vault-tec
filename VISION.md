# Vision

vault-tec exists to keep Morgan's digital mind safe, inspectable, and easy for frontier agents to tend.

The product is not a Claude plugin, dashboard, research-methodology bundle, or autonomous scoring machine. Those surfaces became a second doctrine system and competed with the vault itself.

The product is now simpler:

```text
small deterministic mechanics + vault-local AGENTS.md + frontier model judgment
```

## Canonical truth

- `~/Mind/AGENTS.md` tells agents how to garden the mind.
- `~/Mind/notes/` is the canonical knowledge graph.
- `~/Mind/ops/` is staging and operational residue.
- This repo provides deterministic mechanics around those surfaces.

Generated reports, renders, summaries, cached indexes, pending drafts, and cron outputs are derivative. They can assist judgment; they do not become co-equal truth.

## What code owns

Code earns its place when correctness is mechanical and failure is costly:

- SHA identity and idempotency;
- provenance frontmatter;
- atomic file movement;
- format conversion;
- safe source/sink boundaries;
- deterministic replay witnesses;
- fast local search/render helpers;
- tests proving those contracts.

## What agents own

Agents own semantic judgment:

- reducing raw material into claims;
- deciding what matters;
- connecting thoughts propositionally;
- updating older notes when new thoughts change them;
- challenging weak claims;
- deciding whether a draft is worth preserving.

Those behaviors belong in `AGENTS.md` and operator instructions, not brittle heuristics.

## North star

Raw material should flow into a living, queryable, rewoven wiki:

```text
record -> reduce -> reflect -> reweave -> verify -> rethink -> notes
```

vault-tec's job is to keep the path safe and observable, not to impersonate the gardener.

## Non-goals

- No synthetic health theater.
- No Bobbleheads, Rad Counter, or S.P.E.C.I.A.L. scoring as runtime product.
- No giant active methodology payload duplicating the vault's own doctrine.
- No automatic semantic promotion into `notes/` by local heuristic code.
- No plugin packaging unless it protects a current, tested operator path.
